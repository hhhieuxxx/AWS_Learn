## Clear Resource

* find listener arn
aws elbv2 describe-listeners `
--load-balancer-arn arn:aws:elasticloadbalancing:us-east-1:753387216052:loadbalancer/app/my-load-balancer/f00a15a4102da756 `
--region us-east-1

* delete listener
aws elbv2 delete-listener `
--listener-arn arn:aws:elasticloadbalancing:us-east-1:753387216052:listener/app/my-load-balancer/f00a15a4102da756/621259b9c74dbfe1 `
--region us-east-1

* find targetgroup arn
aws elbv2 describe-target-groups --load-balancer-arn <load-balancer-arn> --region us-east-1

* delete targetgroup
aws elbv2 delete-target-group --target-group-arn <target-group-arn> --region us-east-1

* delete loadbalancer
aws elbv2 delete-load-balancer `
--load-balancer-arn arn:aws:elasticloadbalancing:us-east-1:753387216052:loadbalancer/app/my-load-balancer/f00a15a4102da756 `
--region us-east-1

* delete nat-gateway
    * find
    aws ec2 describe-nat-gateways --region us-east-1
    * delete
    aws ec2 delete-nat-gateway --nat-gateway-id nat-00bee7b8ef3dfa9c6 --region us-east-1

* delete elastic ip
    * find
    aws ec2 describe-addresses --region us-east-1
    * delete
    aws ec2 release-address --allocation-id eipalloc-02c8f48e2ef87f30b --region us-east-1
